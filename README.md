# Master Racing Team (MRT) — Site officiel

Site vitrine responsive du club tunisien Master Racing Team.

## Aperçu
Le site présente le club, ses disciplines (Time Attack, karting, drift et événements), ses engagements, ses partenaires et ses coordonnées.

## Lancer le site
Le fichier principal est `index.html` à la racine du dépôt. Le site peut être publié avec GitHub Pages depuis la branche `main`, dossier `/(root)`.

## Personnalisation à prévoir
- Remplacer le logo typographique provisoire par le logo officiel MRT.
- Remplacer les photos d'illustration par des photos autorisées du club.
- Confirmer les informations institutionnelles et les partenaires.
- Ajouter les calendriers, résultats et actualités officiels.

Les photos présentes sont des illustrations distantes hébergées par Unsplash. Aucun résultat ni calendrier fictif n'est présenté comme officiel.
